# Soundify 0.6.0 — Audio editor

Released 2026-11-11 · versionCode 6 · APK `Soundify-0.6.0.apk` (244 MB)

SHA-256: `2036ec9d034356d84bb44a40205a1278fd79800dfac5b12c968cd7af2b5d5e50`

## Highlights

- **Audio editor.** Import one audio file, trim it on a waveform with draggable
  handles or exact milliseconds, split at the playhead, fade in/out, set
  per-clip volume from −24 to +24 dB, reorder or delete clips, undo/redo, and
  export WAV, FLAC, MP3 or M4A at 44.1 kHz stereo.
- **Non-destructive.** The picked original is never modified. The app keeps its
  own copy under `files/editor/<project>/`; deleting an edit removes only that
  copy.
- **Clean Media audio input** from the 0.5 line is included: audio-only files
  are accepted, history is kept, and the save sheet offers only audio formats
  when the source has no video track.
- **Save sheet** with format choice, name, progress and Cancel. Future-schema
  projects open read-only so a newer version's data is not rewritten.
- **Offline.** No `INTERNET` permission, no accounts, no cloud, no tracking.

## Install and update

0.6.0 is signed with the release key for the first time. Builds before 0.6.0
used the debug key, so uninstall the old app once; app data is removed. After
that, releases update in place.

- APK: `Soundify-0.6.0.apk` on the Releases page.
- Obtainium: add `https://github.com/m0-3az/Soundify` and enable update
  notifications.

## Known limits

- Single-track clip sequence, not a multi-track timeline.
- No recording (planned for 0.9.0), merge, batch convert or real-time effects.
- Preview approximates fades and effects; they are applied on export.
- Clean Media keeps the 6 s chunk / 1 s overlap baseline. The 10 s / 2 s
  listening comparison is still open and is not part of this release.
